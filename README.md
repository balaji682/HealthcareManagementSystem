# Healthcare Management System

A beginner-friendly REST API project built with Java 21, Spring Boot, Spring Data JPA and MySQL. The modules and endpoints follow the supplied Healthcare assignment slides.

## Requirements
- JDK 21
- Eclipse IDE (or another Java IDE)
- MySQL Server 8.x
- Maven (the project includes the Maven wrapper files if generated by your IDE; Eclipse can also import it as an existing Maven project)

## Run in Eclipse
1. Extract `HealthcareManagementSystem.zip`.
2. Open Eclipse and choose **File -> Import -> Maven -> Existing Maven Projects**.
3. Select the extracted `HealthcareManagementSystem` folder and finish the import.
4. Open `src/main/resources/application.properties`.
5. Set `spring.datasource.password` through the `DB_PASSWORD` environment variable, or replace the empty default in the URL settings with your local MySQL root password. For a simple local setup, change `spring.datasource.password=` to your MySQL password.
6. Right-click `HealthcareManagementApplication.java` -> **Run As -> Spring Boot App**.
7. The application runs at `http://localhost:8084` and creates the `healthcare_db` database/tables automatically.

## API endpoints
All endpoints use the base URL `http://localhost:8084`.

| Module | Create | List | Get one | Update | Delete |
|---|---|---|---|---|---|
| Patients | POST `/api/patients` | GET `/api/patients` | GET `/api/patients/{id}` | PUT `/api/patients/{id}` | DELETE `/api/patients/{id}` |
| Doctors | POST `/api/doctors` | GET `/api/doctors` | GET `/api/doctors/{id}` | PUT `/api/doctors/{id}` | DELETE `/api/doctors/{id}` |
| Appointments | POST `/api/appointments` | GET `/api/appointments` | GET `/api/appointments/{id}` | PUT `/api/appointments/{id}` | DELETE `/api/appointments/{id}` |
| Prescriptions | POST `/api/prescriptions` | GET `/api/prescriptions` | GET `/api/prescriptions/{id}` | PUT `/api/prescriptions/{id}` | DELETE `/api/prescriptions/{id}` |
| Medical Records | POST `/api/records` | GET `/api/records` | GET `/api/records/{id}` | PUT `/api/records/{id}` | DELETE `/api/records/{id}` |
| Billing | POST `/api/billing` | GET `/api/billing` | GET `/api/billing/{id}` | PUT `/api/billing/{id}` | DELETE `/api/billing/{id}` |

## Sample requests (Postman -> Body -> raw -> JSON)

### Create patient
`POST http://localhost:8084/api/patients`
```json
{
  "name": "Balaji",
  "dob": "2002-05-15",
  "gender": "Male",
  "contact": "9876543210",
  "address": "Chennai"
}
```

### Create doctor
`POST http://localhost:8084/api/doctors`
```json
{
  "name": "Dr. Ravi Kumar",
  "specialization": "Cardiologist",
  "phone": "9876501234",
  "email": "ravi@example.com"
}
```

### Create appointment (use existing patient and doctor IDs)
`POST http://localhost:8084/api/appointments`
```json
{
  "patient": { "id": 1 },
  "doctor": { "id": 1 },
  "appointment_date": "2026-11-13T10:30:00",
  "reason": "General checkup",
  "status": "Scheduled"
}
```

### Create prescription (use an existing appointment ID)
`POST http://localhost:8084/api/prescriptions`
```json
{
  "appointment": { "id": 1 },
  "medication": "Paracetamol",
  "dosage": "500 mg",
  "instructions": "Take after food"
}
```

### Create medical record (use an existing patient ID)
`POST http://localhost:8084/api/records`
```json
{
  "patient": { "id": 1 },
  "diagnosis": "Seasonal fever",
  "treatment": "Rest and fluids",
  "record_date": "2026-11-12T12:00:00"
}
```

### Create billing entry (use an existing appointment ID)
`POST http://localhost:8084/api/billing`
```json
{
  "appointment": { "id": 1 },
  "amount": 500.00,
  "status": "Paid",
  "billing_date": "2026-11-12T12:30:00"
}
```

## Notes
- Create the patient and doctor before creating an appointment.
- Create an appointment before adding its prescription or billing entry.
- Create a patient before adding a medical record.
- A successful create normally returns **201 Created**, successful reads/updates return **200 OK**, successful delete returns **204 No Content**, and missing IDs return **404 Not Found**.
- This is an educational starter project. Configure your own local MySQL password before running it; do not upload database passwords to GitHub.
